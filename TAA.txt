TAA — Planning de implementación paso a paso

Step 1 — Jitter de la cámara
Objetivo: desplazar sub-píxel la proyección cada frame para acumular muestras distintas.

 Implementar secuencia de Halton(2,3) — 8 puntos es el estándar, evita clumping mejor que random
 Aplicar el offset a la matriz de proyección antes del GBuffer pass
 El offset debe estar en NDC: jitter = (halton - 0.5) * 2.0 / screenSize
 Guardar currentJitter y prevJitter como uniforms — necesarios para eliminar el jitter del motion vector
 El jitter no se aplica al cálculo de motion vectors de geometría estática — usar prevViewProjectionNoJitter para reprojectar
 El cabeceo de cámara va fuera del jitter — prevViewProjectionNoBob separado para motion vectors de geometría del mundo


Step 2 — Motion Vector buffer
Objetivo: para cada píxel, almacenar cuánto se ha movido respecto al frame anterior en UV space.

 Crear render target RG16Float — suficiente precisión, limpiar a (0,0) cada frame
 En el GBuffer vertex shader, calcular:

wgsllet clipCurr = camera.viewProjectionNoJitter * vec4(worldPos, 1.0);
let clipPrev = camera.prevViewProjectionNoBob * vec4(worldPos, 1.0);
let ndcCurr  = clipCurr.xy / clipCurr.w;
let ndcPrev  = clipPrev.xy / clipPrev.w;
motionVector = (ndcCurr - ndcPrev) * 0.5; // UV space

 Para objetos animados/skinned: usar prevWorldPos del vertex anterior
 Guardar prevViewProjection después de aplicar todo — rotación, traslación, cabeceo


Step 3 — History buffer
Objetivo: mantener el resultado acumulado del frame anterior para mezclarlo con el actual.

 Crear dos render targets RGBA16Float en ping-pong — historyA y historyB
 Alternar cuál es "current" y cuál es "history" cada frame
 En el primer frame (o tras resize): inicializar el history con el frame actual sin mezcla — flag isFirstFrame
 Guardar también un historyDepth buffer — necesario para disocclusion detection


Step 4 — Reprojección
Objetivo: encontrar dónde estaba el píxel actual en el frame anterior.

 En el TAA shader, reprojectar usando el motion vector:

wgsllet reprojectedUV = uv - motionVector;

 Verificar que reprojectedUV está en [0,1] — si sale de pantalla, usar solo el frame actual (blend = 1.0)
 Usar closest depth en neighborhood 3×3 para el motion vector — el píxel más cercano a cámara domina en bordes de objetos:

wgslvar closestDepth = 1.0;
var closestMV    = vec2(0.0);
// loop 3x3, busca min depth, guarda su MV

 Samplear el history con el UV reprojectado usando filtrado bicúbico Catmull-Rom — bilinear introduce blur innecesario en el history


Step 5 — Neighborhood Clamping en YCoCg
Objetivo: rechazar muestras del history que ya no son válidas — principal defensa contra ghosting.

 Convertir a espacio YCoCg antes de cualquier operación:

wgslfn rgbToYCoCg(c: vec3<f32>) -> vec3<f32> {
    return vec3(
         0.25*c.r + 0.5*c.g + 0.25*c.b,
         0.50*c.r            - 0.50*c.b,
        -0.25*c.r + 0.5*c.g - 0.25*c.b
    );
}

 Recoger neighborhood 3×3 del frame actual en YCoCg
 Calcular mean y variance del neighborhood
 Clamp del history a mean ± gamma * stdDev — gamma entre 1.0 y 1.5:

wgsllet colorMin = mean - gamma * stdDev;
let colorMax = mean + gamma * stdDev;
historySample = clamp(historySample, colorMin, colorMax);

 Volver a RGB después del clamp


Step 6 — Blend adaptativo
Objetivo: mezclar history con frame actual con un factor que se adapta al movimiento y disocclusion.

 Factor base: alpha = 0.1 (90% history, 10% current) — estándar para cámara quieta
 Blend adaptativo por magnitud de motion vector:

wgsllet motionLength = length(motionVector);
let blendFactor  = mix(0.1, 0.3, saturate(motionLength * 20.0));

 Disocclusion detection por depth:

wgsllet prevDepth = textureSample(historyDepth, sampler, reprojectedUV).r;
let currDepth = textureSample(gLinearDepth, sampler, uv).r;
let disoccluded = abs(currDepth - prevDepth) > 0.05 * currDepth;
let blendFactor = select(blendFactor, 0.9, disoccluded);

 Blend en YCoCg, convertir a RGB al final:

wgsllet result = mix(historySample, currentSample, blendFactor);

Step 7 — Anti-flicker (luminance weighting)
Objetivo: estabilizar highlights especulares y zonas de alta frecuencia que parpadean.

 Ponderar cada sample por el inverso de su luminancia antes de mezclar — reduce el peso de píxeles muy brillantes:

wgsllet lumaHistory = rgbToYCoCg(historySample).x;
let lumaCurrent = rgbToYCoCg(currentSample).x;
let weightHistory = 1.0 / (1.0 + lumaHistory);
let weightCurrent = 1.0 / (1.0 + lumaCurrent);
// normalizar y mezclar con los pesos

 Alternativa log space: convertir a log antes de mezclar, exponenciar al final — más estable pero cuidado con NaNs si hay negros puros


Step 8 — Sharpening post-TAA
Objetivo: recuperar nitidez perdida por el blur temporal durante movimiento.

 Aplicar un sharpen simple tipo unsharp mask después del blend:

wgsllet blurred  = (n + s + e + w) * 0.25;
let sharpened = current + (current - blurred) * sharpenStrength; // 0.3–0.5
```
- [ ] O usar el RCAS que ya tienes de FSR — aplicarlo después de TAA antes de FSR EASU
- [ ] Mip bias negativo en todas las texturas del GBuffer pass: `textureSampleBias(..., -0.5)` — contrarresta el blur del jitter

### Step 9 — Casos especiales

**Objetivo**: evitar artefactos en situaciones problemáticas conocidas.

- [ ] **Normal maps**: samplear en GBuffer con UVs sin jitter — el jitter no debería desplazar el sample de texturas, solo la posición del vértice
- [ ] **Transparencias**: escribir motion vectors como si fueran sólidas si opacity > 0.5, o renderizar transparencias después de TAA
- [ ] **Partículas y efectos**: marcar con "responsive AA" flag — blend factor `0.5` forzado para que no acumulen ghosting
- [ ] **Primer frame / resize**: skip del history, blend = 1.0, solo frame actual
- [ ] **Cabeceo**: `prevViewProjectionNoBob` para geometría estática, `prevViewProjectionFull` para objetos del mundo con posición propia
```
